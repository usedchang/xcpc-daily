本质ad-hoc,知道结论就能简单用邻项交换证明，不知道死活做不出。

先给出一个本质一点的结论: 数组按 $\max(a_i,b_i)$ 后操作一定不劣

然后尝试证明：

- 单独考虑 $a_i$,前面的数小后面的数大能保证所有位置都尽可能考虑 

- 单独考虑 $b_i$,前面的数小保证了后继更新值更小。

- 考虑 $a_i$ 与 $b_{i+1}$ ,如果 $a_i>b_{i+1}$ 那么交换一定不劣。
因为如果 $x \le a_{i+1}$,$x=max(x,b_{i+1})$ 后，如果 $x=b_{i+1}$ 保证一定能进入 $a_i$,答案至少为 2，否则 $x>a_{i+1}$ ,则是否交换答案均为0.

- 考虑 $b_i$ 与 $a_{i+1}$ 如果  $b_i>a_{i+1}$ ,交换不会产生影响。


```cpp
#include<bits/stdc++.h>
using namespace std;
#define endl '\n'
typedef long long ll;
int main(){
    cin.tie(0)->ios::sync_with_stdio(false);
    int n;cin>>n;
    vector<ll>a(n+1);
    vector<ll>b(n+1);
    vector<int>p(n+1);
    iota(p.begin(),p.end(),0);
    for(int i=1;i<=n;i++) cin>>a[i]>>b[i];
    sort(p.begin()+1,p.end(),[&](int x,int y){
        if(max(a[x],b[x])!=max(a[y],b[y])) return max(a[x],b[x])<max(a[y],b[y]);
        if(a[x]!=a[y]) return a[x]<a[y];
        return b[x]<b[y];
    });
    ll x=0,ans=0;
    for(int i=1;i<=n;i++){
        if(x<=a[p[i]]){
            x=max(x,b[p[i]]);
            ans++;
        }
    }
    cout<<ans<<endl;
    return 0;
}
```
