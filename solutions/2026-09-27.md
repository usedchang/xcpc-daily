一道锻炼注意力和观察性质的题目

对于每个前缀中子序列最小值和最大值之和最多出现的那个数字。

核心观察:

- 每个前缀如果按顺序排序，众数大多情况下都是最大值与最小值之和。

- 当且仅当最小值只出现一次且出现的数的个数少于3种才违背以上规律，此时众数为最大值的两倍。

- 考虑要记录每个前缀最大值与最小值同时使用他们之间种类个数出现次数等判定，可以使用 $\texttt{std::map}$ 容器。

```cpp
#include<bits/stdc++.h>
using namespace std;
#define endl '\n'
typedef long long ll;
void solve(){
    int n;cin>>n;
    vector<ll>a(n+1);
    for(int i=1;i<=n;i++) cin>>a[i];
    map<ll,ll>mp;
    for(int i=1;i<=n;i++){
        mp[a[i]]++;
        auto itL=mp.begin();
        auto itR=mp.rbegin();
        if(itL->second!=1||mp.size()>2) cout<<itL->first+itR->first<<' ';
        else cout<<2*itR->first<<' ';
    }
    cout<<endl;
}
int main(){
    cin.tie(0)->ios::sync_with_stdio(false);
    int T;cin>>T;
    while(T--) solve();
    return 0;
}
```
