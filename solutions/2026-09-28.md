一道我觉得很考验思维和观察底力的题。

核心观察:

- $f(x)=\frac{x}{A_n}+f(x \bmod A_n)$

- 要求的是 $f(x)=m$ 的 $x$ 有多少个

-  $f(x\bmod A_n)$ 的上界不超过 $A_n-1$


要求 $f(x)=m$ 的值的 $x$ 种类数。

根据第一条核心观察就是求 $f(x \bmod A_n)=f(y)=m- \frac{x}{A_n}$ 的 $y$ 种类数。
 
又因为 $f(y)$ 可以取遍 $[0,\min(A_n-1,m)]$(第三条核心观察).

所有其实答案就是求 $f(y)$ 取值这些数的时候的情况总和,可以用桶统计这些情况，前缀和累加方案数。

最后算法考虑用 $\texttt{dp}$ 配合 $\texttt{two pointer}$ 的技巧快速求出 $f$，然后使用 `桶` 和 `前缀和` 的思想统计答案。

```cpp
#include<bits/stdc++.h>
using namespace std;
#define endl '\n'
typedef long long ll;
const ll N=1e6+5;
ll dp[N],cnt[N],sum[N];
int main(){
    cin.tie(0)->ios::sync_with_stdio(false);
    int n,q;
    cin>>n>>q;
    vector<ll>a(n+1);
    for(int i=1;i<=n;i++) cin>>a[i];
    int p=1;
    for(int i=1;i<=a[n];i++){
        while(p+1<=n&&i>=a[p+1]) p++;
        dp[i]=i/a[p]+dp[i%a[p]];
        cnt[dp[i]]++;
    }
    for(int i=1;i<=a[n];i++) sum[i]=sum[i-1]+cnt[i];
    while(q--){
        int x;cin>>x;
        if(x>a[n]) x=a[n];
        cout<<sum[x]<<' ';
    }
    cout<<endl;
    return 0;
}
```  
