## A. Square Kingdom

已知序列 $h_i=(i+\frac{b}{a})^2 \ (i=1,2,3…,n)$ 求 $\Delta h_{i,j}=h_j-h_i=(j-i)(i+j+\frac{2b}{a}) \ 1≤i＜j≤n$ 从小到大排序后的第 $k$ 个元素的最简分数形式
整理一下有 $\Delta h_{i,j}=\frac{(j-i)(a(i+j)+2b)}{a}$ 设 $t=j-i$ 有 $\Delta h_{i,j}=\frac{t(at+2ai+2b)}{a}$ 由于 $a$ 为常数， $\Delta h_{i,j}$ 只与 $t(at+2ai+2b)$ 有关
我们记 $H=t(at+2ai+2b)$ ，易知答案 $ans$ 在 $[H|_{\{t,i\}=\{1,1\}},H|_{\{t,i\}=\{n-1,n\}}]$ 上单调，考虑对 $H$ 二分答案

> [!question] 如何写check
> 本题要求的答案 $ans$ 为第 $k$ 个小的元素，所以我们需要 check 答案为 $mid$ 时 $H≤mid$ 的个数 $cnt$ ，若 $cnt<k$ 则答案在 $[mid+1,r]$ 区间内，否则答案在 $[l,mid]$ 区间内

我们发现，若 $t$ 为常数，则 $H$ 是关于 $i$ 的等差数列，此时可以 $O(1)$ 计算 $H≤mid$ 的个数，所以我们在 `check(mid)` 的过程中枚举 $t$ 即可，但 $t\in[1,k-1]$ ，暴力枚举 $t$ 的时间复杂度为 $O(k)$ 导致超时，而当 $t=x$ 的首项大于 $mid$ 时， $t=x+1,x+2…,n$ 的首项必然大于 $mid$ ，故枚举到第一个首项大于 $mid$ 的 $t$ 值时可以直接跳出循环

> [!question] 为什么能保证不超时
> 若存在 $\Delta h_{i,j}≤\frac{ans}{a}$ 则所有 $i≤i'＜j'≤j$ 都有 $\Delta h_{i'.j'}≤\frac{ans}{a}$
> 即 $\Delta h_{i,j}≤\frac{ans}{a}$ 时共有 $\frac{[i+(j-1)](j-i)}{2}$ 个数符合条件
> 设 $i=1,j=x$ 时 $\frac{[1+(x-1)](x-1)}{2}=\frac{x(x-1)}{2}=k$
> 解得 $x=\sqrt{2k}+\frac{1}{2}$ ，$t_{max}=x-1=\sqrt{2k}-\frac{1}{2}$
> 所以当我们的 $t$ 枚举到 $\sqrt{2k}$ 时，必定存在 $cnt≥k$ 返回
> 即枚举 $t$ 最多进行 $\sqrt{2k}$ 次，一次 check 的时间复杂度为 $O(\sqrt{2k})$

```cpp
typedef __int128_t i128;
i128 n,k,a,b,tmax;

inline i128 read()
{
    i128 x=0,f=1;
    char ch=getchar();
    while(ch<'0'||ch>'9')
    {
        if(ch=='-')
            f=-1;
        ch=getchar();
    }
    while(ch>='0' && ch<='9')
        x=x*10+ch-'0',ch=getchar();
    return x*f;
}

void write(i128 x)
{
    if(x<0)
        putchar('-'),x=-x;
    if(x>9)
        write(x/10);
    putchar(x%10+'0');
    return;
}

i128 gcd(i128 a,i128 b)
{
    return b ? gcd(b,a % b) : a;
}

bool check(i128 mid)
{
    i128 cnt=0;
    for (int t = 1; t <= tmax; t++)
    {
        if(a*t*t+2*a*t+2*b*t>mid)
            break;
        i128 maxi=min((mid-a*t*t-2*b*t)/(2*a*t),n-t);
        if(maxi>0)
        {
            cnt+=maxi;
            if(cnt>=k)
                return 0;
        }
    }
    return cnt<k;
}

void solve()
{
    n=read(),k=read(),a=read(),b=read();
    tmax=min(n,(i128)1e12);
    i128 l=3*a+2*b,r=(n-1)*(a*(n+2*n*(n-1))+2*b),mid=l+r>>1;
    while(l<=r)
    {
        if(check(mid))
            l=mid+1;
        else
            r=mid-1;
        mid=l+r>>1;
    }
    i128 gcdv=gcd(l,a);
    write(l/gcdv),putchar(' '),write(a/gcdv);
}
```

时间复杂度 $O(\sqrt{2k}(\log a+\log n))$ 
常数优化：优化初始 `r` 的值 $r=H_{max}=a(2k+2\sqrt{2k})+2b\sqrt{2k}$ ，时间复杂度为 $O(\sqrt{2k}(\log a+\log k))$
