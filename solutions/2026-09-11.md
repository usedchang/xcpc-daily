简要题意:
给定一个字符串 $S$，原始串中含有`spbsu`,$S$ 是原始串通过交换任意两个相邻的不同的字符(保证生成串和原始串都含有`spbsu`作为子序列)后生成的,求最小交换次数

就是求允许交换相邻项还原出`spbsu`子串的最小代价
考虑对于已经选定的某一个`spbsu`,选定某个下标集合
使得 $S_{p_1}=s,S_{p_2}=p,S_{p_3}=b,S_{p_4}=s,S_{p_5}=u$

那就转化为了允许任意次对某个 $p_i$ 位置进行`+1`或`-1`操作使得 $p_{i+1}=p_{i}+1$ 成立，求最小操作次数。

设最终连续的下标为 $q$,形成如 $x,x+1,\dots,x+n-1$的序列
所以第 $i$ 个下标的目标为 $x+i-1$。

那么有使得操作代价最小化代价为
$Cost=|p_i-q_i|=|p_i-(x+i-1)|=|p_i-(i-1)-x|$ 

把 $p_i-(i-1)$ 看作一个整体 $s_i$。 就是最小化 $|s_i-x|$
的代价，根据[中位数定理](https://blog.51cto.com/u_15345034/5001795?),所有位置与$s_{mid}$ 的绝对值之差就是最小值，且最小值为

$$
s_3-s_1+s_3-s_2+s_4-s_3+s_5-s_3=s_4+s_5-s_1-s_2
$$

也就是

$$
f(p)=p_4+p_5-p_1-p_2-6
$$

发现答案就是最小化目标函数 $f(p)$ 的值，最小化函数代价枚举`b`位置预处理前后缀或$dp$ 处理一下就好了

```cpp
#include<bits/stdc++.h>
using namespace std;
#define endl '\n'
typedef long long ll;
const ll INF=1e18;
int main(){
    cin.tie(0)->ios::sync_with_stdio(false);
    int n;string s;
    cin>>n>>s;
    s="&"+s;
    string t="&spbsu";
    vector<int>u(n+2,n+1);
    vector<int>su(n+2,n+1);
    for(int i=n;i>=1;i--){
        if(s[i]=='u') u[i]=min(i,u[i+1]);
        else u[i]=u[i+1];
        if(s[i]=='s'&&u[i+1]!=n+1) su[i]=i+u[i+1];
        else su[i]=su[i+1];
    }
    ll S=0,SP=0;
    ll ans=INF;
    for(int i=1;i<=n;i++){
        if(s[i]=='s') S=i;
        else if(S!=0&&s[i]=='p') SP=S+i;
        if(SP!=0&&su[i]!=n+1) {
            ans=min(ans,-SP+su[i]-6LL);
        }
    }
    cout<<ans<<endl;
    return 0;
}
```
