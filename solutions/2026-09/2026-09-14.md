要求构造3个严格不超过 $n$ 的数，使得他们的 lcm 最大化
首先当 $n \leq 2$ 时易知答案就是 $n$.

想要让三数 lcm 尽可能大，那就尽可能想要三数两两互质，
对于两个奇数夹一个偶数情况:$A=B+1,B=C+1$
我们发现答案可以取到 $lcm(A,B,C)=A \times B \times C$
最优情况,否则 $A$ 与 $C$ 同为偶数一定有 $lcm(A,C)=2$.
因为假设三数存在不互质的情况
则有 $lcm(A,B,C) \leq \frac{A \times B \times C }{2}$
,此时一定可以取到的是 $lcm(A-1,B-1,C-1)=(A-1)\times (B-1) \times (C-1)$.

当 $A \bmod 3 \neq 0$ 时可以取到
$lcm(A,B,C-1)=A \times B \times (C-1)$
对几种情况分一下类可以得出答案。

```cpp
#include<bits/stdc++.h>
using namespace std;
#define endl '\n'
typedef long long ll;
void solve(){
    ll n;cin>>n;
    if(n<=2){
        cout<<n<<endl;
        return;
    }
    if(n&1) cout<<n*(n-1)*(n-2)<<endl;
    else{
        if(n%3!=0) cout<<n*(n-1)*(n-3)<<endl;
        else cout<<(n-1)*(n-2)*(n-3)<<endl;
    }
}
int main(){
    cin.tie(0)->ios::sync_with_stdio(false);
    int T=1;//cin>>T;
    while(T--) solve();
    return 0;
}
```
