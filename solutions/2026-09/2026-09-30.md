一道通信题

你需要对一个特定的字符串进行编码成严格不超过 $2 \times 10^{18}$ 的数字，然后还原。

这个字符串上界长度是 $75$,显然直接对其进行3进制编码是不现实的做法 : $3^{75} \gg2\times 10^{18}$.

接着我们考虑怎么唯一的编码一个字符串？

观察到每个字符串 $s$ 可以拆分成 $(+s_1+|+s_2+)+s_3$ 的形式。

由 $n$ 个三元组`(`,`|`,`)` 构成的字符串个数可以很好的用`动态规划`的方式统计而出: $dp_{n}=\sum_{u+v+w=n-1}dp_u dp_v dp_w$(熟悉这个式子的人可以一眼看出这是卡特兰数三阶变种，当然你看不出来也可以做题)。然后算一下这个式子在 $n=25$ 的时候的上界,发现是严格小于 $2 \times 10^{18}$ 的。我们可以根据以上性质进行编码与解码

### 编码阶段
我们需要设计一个函数求出某个字符串在反回该长度下的序数。
假设这个字符串已经被拆成了$(+s_1+|+s_2+)+s_3$的形式。我们利用`进制`的知识可以知道如果我们取得了 

- $s_1$ 在长 $|s_1|$ 字符串中的序数 $p_1$ 以及长为 $|s_1|$ 的字符串的所有合法数量 $dp_{|s_1|}$。 

- $s_2$ 在长 $|s_2|$ 字符串中的序数 $p_2$ 以及长为 $|s_2|$ 的字符串的所有合法数量 $dp_{|s_2|}$。

- $s_3$ 在长 $|s_3|$ 字符串中的序数 $p_3$ 以及长为 $|s_3|$ 的字符串的所有合法数量 $dp_{|s_3|}$。

那么当前字符串的序数可以唯一被确定为 $\sum_{u}^{u_0}\sum_{v}^{v_0}{dp_{u}dp_{v}dp_{n-1-u-v}}+(p_1\times dp_{|s_2|}+p_2)\times dp_{|s_3|}+p_3$,其中 $u_0$,$v_0$,$w_0$ 由`(`,`|`,`)`位置划分决定。
由于确定序数的算法涉及了较小的子问题确定较大的父问题，考虑使用递归算法解决。

为什么能够这样编码?(为什么字符串和数字满足双射关系?)

- 任何一个字符串都能唯一被划分为 $(+s_1+|+s_2+)+s_3$ 的形式

- 对于一个独立的$(u,v,w)$ 组合一定存在唯一映射的数字和字符串

- 可以使用前缀和结构统计更为靠前的合法划分总和数量


### 解码阶段
我们需要设计一个函数通过数字解出一个唯一的字符串，并且这个字符串可以利用编码阶段的算法还原出数字。
仔细观察以上编码方式，每次从小到大枚举 `u`,`v`,然后计算 数字是否能够囊括这个前缀，如果能就直接减去这一块贡献，否则就按`u`,`v`,`w`进制逐项还原。

```cpp
#include<bits/stdc++.h>
using namespace std;
#define endl '\n'
typedef long long ll;
ll r[30];
int n;
string s;
ll encode(int n,int pos){
    if(n==0) return 0;
    int p=pos,d=0,q=-1,e=-1;//p='(',q='|',e=')'
    for(int i=p+1;i<(int)s.size();i++){
        if(s[i]=='(') d++;
        else if(s[i]==')'){
            if(d==0){
                e=i;
                break;
            }
            d--;
        }
        else if(d==0&&q==-1) q=i;
    }
    int u0=(q-p-1)/3,v0=(e-q-1)/3,w0=n-1-u0-v0;
    ll rk=0;
    for(int u=0;u<=n-1;u++){
        for(int v=0;u+v<=n-1;v++){
            int w=n-1-u-v;
            if(u==u0&&v==v0){
                ll p1=encode(u,p+1);
                ll p2=encode(v,q+1);
                ll p3=encode(w,e+1);
                rk+=(p1*r[v]+p2)*r[w]+p3;
                return rk;
            }
            rk+=r[u]*r[v]*r[w];
        }
    }
    return rk;
}
string decode(int n,ll code){
    if(n==0) return string();
    for(int u=0;u<=n-1;u++){
        for(int v=0;u+v<=n-1;v++){
            int w=n-1-u-v;
            ll cur=r[u]*r[v]*r[w];
            if(code>=cur) {
                code-=cur;
                continue;
            }
            ll p3=code%r[w];code/=r[w];
            ll p2=code%r[v];code/=r[v];
            ll p1=code;
            return "("+decode(u,p1)+"|"+decode(v,p2)+")"+decode(w,p3);
        }
    }
    return string();
}
int main(){
    cin.tie(0)->ios::sync_with_stdio(false);
    r[0]=1;
    for(int n=1;n<=25;n++){
        for(int u=0;u<=n-1;u++){
            for(int v=0;u+v<=n-1;v++){
                r[n]+=r[u]*r[v]*r[n-1-u-v];
            }
        }
    }
    string op;cin>>op;
    int T;cin>>T;
    while(T--){
        if(op=="encode"){
            cin>>n>>s;
            cout<<encode(n,0)<<endl;
        }
        else{
            ll x;
            cin>>n>>x;
            cout<<decode(n,x)<<endl;
        }
    }
    return 0;
}
```
