给定 $2 \times n$ 的网格博弈，先手在 $(1,1)$ 开始取数，后手在 $(2,n)$ 开始取数，求最后胜者？

从先手角度开始考虑，我想要取遍网格图中从 $1$ 号位置开始一直到 $i$ 号位置的前缀,发现一定是从 $(1,1)$ 走到 $(1,i)$ ,然后在走到 $(2,i)$后绕回 $(2,1)$ 最优，因为这样你能保证走到 $(2,i)$ 的速度是最快的，对手想要抢夺 $(2,i)$ 一定要比这个做到更快。 

这样得出核心观察:

- 先手一定能够取到 $(1,\lfloor \frac{n}{2} \rfloor)$ 上两行的所有数

- 当 $n$ 是奇数时，先手从 $(1,1)$ 走到 $(1,\lfloor \frac{n}{2} \rfloor)$ 时，后手可以也一定用相同的方式从 $(2,n)$ 走到 $(2,\lfloor \frac{n}{2} \rfloor+1)$ ,
此时后手有两种选择: 

1.向左走一步，使得先手取遍上面一整行。

2.向上走一步，使得先手取遍前  $\lceil \frac{n}{2} \rceil$ 列两行的和。
  
综上，博弈的胜负判定是 $\max({P_k,\min({P_{k+1},R_1})}) \times 2>S$ ($P$ 表示两行前缀和,$R_1$ 表示第一行的整行和，$S$ 表示整个网格图的和) 。

```cpp
#include<bits/stdc++.h>
using namespace std;
#define endl '\n'
typedef long long ll;
void solve(){
    int n;cin>>n;
    vector<array<ll,2>>a(n+2);
    ll S1=0,S=0;
    for(int i=1;i<=n;i++) cin>>a[i][0],S1+=a[i][0],S+=a[i][0];
    for(int i=1;i<=n;i++) cin>>a[i][1],S+=a[i][1];
    int cnt=n/2;
    ll T1=0,T2=0;
    for(int i=1;i<=cnt;i++) T1+=a[i][0];
    for(int i=1;i<=cnt;i++) T1+=a[i][1];
    ll val=max(T1,min(T1+a[cnt+1][0]+a[cnt+1][1],S1));
    if(val*2>S) cout<<"Mandy"<<endl;
    else if(val*2==S) cout<<"draw"<<endl;
    else cout<<"brz"<<endl;
}
int main(){
    cin.tie(0)->ios::sync_with_stdio(false);
    int T;cin>>T;
    while(T--) solve();
    return 0;
}
```
