# 题解目录

本目录存放每道题的本地 Markdown 题解。

## 文件名约定

- 默认：与 `data.json` 中该题的 `date` 相同，例如 `2026-09-08.md`。
- 也可显式指定：在 `data.json` 的题目里加 `"solution": "其它文件名"`（不带目录、`.md` 可省略）。
- 以 `_` 开头或名为 `README` 的 `.md` 会被忽略（本文件即如此）。

## 内容格式

标准 Markdown，支持标题、加粗、行内代码、代码块（带语言名）、列表、表格、引用、图片等。
GitHub 风格相对链接可以在构建后 fetch 回退模式下使用，但内联打包时相对路径需注意 base。

## Hint（提示）

Hint 直接写在 `data.json` 里，与题解正文独立，仅在点击标题时展开，类似 codeforces 的 Hint：

```json
{
  "date": "2026-09-08",
  "source": "…",
  "title": "…",
  "link": "…",
  "hints": [
    "第一个提示：可以按位考虑。",
    "第二个提示：用 `trie` 维护。"
  ]
}
```

每个字符串是一个 hint，按顺序显示为 `Hint 1`、`Hint 2`……，点击标题展开/收起，内容也走 Markdown 渲染。
