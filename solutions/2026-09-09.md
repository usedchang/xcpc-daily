$$
f(x)=(ax+b) \oplus (a(x+1)+b)
$$

$$
f(x)=(ax+b) \oplus (ax+b+a)
$$

设 $ax+b=s$

$$
f(x)=s \oplus (s+a)=s+(s+a)-2(s \& (s+a))  \tag{1}
$$

$$
s \& (s+a)  \leq s \tag{2}
$$

其中(2)在a=0时能够取到其中一个下界,
由 (1),(2) 式得出 (3):

$$
f(x)=2s + a -2(s \& (s+a)) \geq a \tag{3}
$$

证明了下界可以取到 $a$,还要证明一定可以取到下界
当

$$
s \subseteq (s+a) 
$$

能够取到下界

当 $s \&a=(ax+b)\&a=0$时式子成立.

等价

$$
(\frac{a}{q}x+\lfloor \frac{b}{q} \rfloor) \&(\frac{a}{q})=0  ,q取a的 lowbit
$$

我们知道 `&`在可以等价于二进制模运算上乘法,那么

$$
(\frac{a}{q}x+\lfloor \frac{b}{q} \rfloor) \times (\frac{a}{q})=0  \pmod {2^k},k表示二进制最高位
$$

若有

$$
(\frac{a}{q}x+\lfloor \frac{b}{q} \rfloor) =0  \pmod {2^k},k表示二进制最高位
$$

成立，

则一定能取到，那么答案一定能取到下界，如果存在逆元就能很简单解出 $x$ 的值，可惜不一定存在。

但是如何保证在 $\bmod {2^k}$ 意义下分母 $q$ 与 $2^k(k表示 \frac{a}{q}的二进制位数)$ 互质?

显然任意分母 $a$ 只需要除以他的 $q=lowbit(a)=a\&-a$ 就一定能转化为一个与 $2^k$ 互质的数。

这样我们只关系高位上按位与为0,有转化

$$
 \frac{a}{q}x+\lfloor \frac{b}{q} \rfloor =0 \pmod {2^k}
$$

$$
 x=-\dfrac{\lfloor \frac{b}{q} \rfloor}{ \frac{a}{q}} \pmod {2^k}
$$

最后用 [exgcd 算法](https://oi-wiki.org/math/number-theory/gcd/#%E6%89%A9%E5%B1%95%E6%AC%A7%E5%87%A0%E9%87%8C%E5%BE%97%E7%AE%97%E6%B3%95)求逆元就可以解出答案
```cpp
#include<bits/stdc++.h>
using namespace std;
#define endl '\n'
typedef long long ll;
ll exgcd(ll a,ll b,ll &x,ll&y){
    if(!b){
        x=1,y=0;
        return a;
    }
    ll d=exgcd(b,a%b,y,x);
    y-=a/b*x;
    return d;
}
ll inv(ll t,ll mod){
    ll x,y;
    exgcd(t,mod,x,y);
    return (x%mod+mod)%mod;
}
int main(){
    cin.tie(0)->ios::sync_with_stdio(false);
    int T;cin>>T;
    while(T--){
        ll a,b;cin>>a>>b;
        ll q=(a&-a);
        ll A=a/q,B=b/q;
        ll k=__lg(A)+1;
        const ll mod=1LL<<k;
        cout<<a<<' '<<(mod-B*inv(A,mod)%mod)<<endl;
    }
    return 0;
}
```
